`List` displays a vertical collection of items and lets the user select one of them. It implements
`StatefulWidget`, meaning selection and scroll position are tracked in a `ListState` value that
lives in your application state and is updated by your event loop. On each render, `List` reads
that state to highlight the selected row and scroll the viewport so the selection stays visible.

## Creating a List

`List::new` accepts any iterator whose items convert to `ListItem`. The simplest form takes an
array or slice of string slices:

```rust
use ratatui::widgets::List;

let list = List::new(["Item 1", "Item 2", "Item 3"]);
```

You can also collect an iterator into a `List`:

```rust
use ratatui::widgets::List;

let list: List = (0..5).map(|i| format!("Item {i}")).collect();
```

## ListItem

`ListItem` wraps any type that converts to `Text`, allowing styled multi-line entries:

```rust
use ratatui::style::Stylize;
use ratatui::text::{Line, Text};
use ratatui::widgets::{List, ListItem};

let items = vec![
    ListItem::new("Plain item"),
    ListItem::new("Styled item".green().bold()),
    ListItem::new(Text::from(vec![
        Line::from("Two-line item"),
        Line::from("  second line".dark_gray()),
    ])),
];

let list = List::new(items);
```

## Styling and Highlight

Configure the base style, the style applied to the selected item, and the symbol shown to its left:

```rust
use ratatui::style::{Style, Stylize};
use ratatui::widgets::{Block, List};

let list = List::new(["Item 1", "Item 2", "Item 3"])
    .block(Block::bordered().title("My List"))
    .style(Style::new().white())
    .highlight_style(Style::new().reversed().bold())
    .highlight_symbol("» ")
    .repeat_highlight_symbol(true); // repeat the symbol on every line of multi-line items
```

`highlight_spacing` controls whether the space for the highlight symbol is always reserved or only
when something is selected (`HighlightSpacing::WhenSelected` vs `HighlightSpacing::Always`).

## List Direction

By default the first item is at the top. Reverse this with `ListDirection::BottomToTop`:

```rust
use ratatui::widgets::{List, ListDirection};

let list = List::new(["A", "B", "C"])
    .direction(ListDirection::BottomToTop);
```

## ListState

`ListState` tracks two values:

| Field | Accessor | Description |
|---|---|---|
| `selected` | `selected()` / `select()` | Index of the highlighted item, or `None` |
| `offset` | `offset()` / `offset_mut()` | Index of the first visible item |

Keep `ListState` in your application struct and pass a mutable reference to
`render_stateful_widget`:

```rust
use ratatui::Frame;
use ratatui::layout::Rect;
use ratatui::style::{Style, Stylize};
use ratatui::widgets::{Block, List, ListState};

struct App {
    items: Vec<String>,
    list_state: ListState,
}

impl App {
    fn new() -> Self {
        Self {
            items: vec![
                "Buy groceries".into(),
                "Walk the dog".into(),
                "Read a book".into(),
            ],
            list_state: ListState::default().with_selected(Some(0)),
        }
    }

    fn select_next(&mut self) {
        self.list_state.select_next();
    }

    fn select_previous(&mut self) {
        self.list_state.select_previous();
    }

    fn render(&mut self, frame: &mut Frame, area: Rect) {
        let list = List::new(self.items.iter().map(String::as_str))
            .block(Block::bordered().title("Tasks"))
            .highlight_style(Style::new().reversed())
            .highlight_symbol("> ");

        frame.render_stateful_widget(list, area, &mut self.list_state);
    }
}
```

## Scroll Padding

`scroll_padding` keeps a number of items visible above and below the selected item, preventing the
selection from sitting flush at the edge of the viewport:

```rust
use ratatui::widgets::List;

let list = List::new(["A", "B", "C", "D", "E"])
    .scroll_padding(2); // keep 2 items visible before and after selection
```

## Complete Stateful Example

```rust
use ratatui::Frame;
use ratatui::layout::{Constraint, Layout};
use ratatui::style::{Modifier, Style, Stylize};
use ratatui::text::Line;
use ratatui::widgets::{Block, HighlightSpacing, List, ListItem, ListState};

struct App {
    items: Vec<&'static str>,
    state: ListState,
}

impl App {
    fn new() -> Self {
        Self {
            items: vec!["Apples", "Bananas", "Cherries", "Dates", "Elderberries"],
            state: ListState::default().with_selected(Some(0)),
        }
    }

    fn render(&mut self, frame: &mut Frame) {
        let area = frame.area();

        let items: Vec<ListItem> = self
            .items
            .iter()
            .enumerate()
            .map(|(i, item)| {
                let style = if i % 2 == 0 {
                    Style::new().on_black()
                } else {
                    Style::new().on_dark_gray()
                };
                ListItem::new(Line::from(*item)).style(style)
            })
            .collect();

        let list = List::new(items)
            .block(Block::bordered().title(" Fruit "))
            .highlight_style(
                Style::new()
                    .add_modifier(Modifier::BOLD)
                    .add_modifier(Modifier::REVERSED),
            )
            .highlight_symbol("▶ ")
            .highlight_spacing(HighlightSpacing::Always)
            .scroll_padding(2);

        frame.render_stateful_widget(list, area, &mut self.state);
    }
}
```

<Tip>
  Call `state.select_next()` and `state.select_previous()` in your key-event handler to move the
  selection. `select_next()` moves the index forward (clamped at the last item after rendering) and
  `select_previous()` moves it backward (clamped at `0`). Use `select_first()` and `select_last()`
  to jump to the ends of the list.
</Tip>

<Note>
  `List` differs from `Table` in that it does not handle columns or a header row, and item height
  is determined automatically by the content. Use `List` for single-column, variable-height data
  and `Table` for structured multi-column data.
</Note>
