Ratatui ships with a comprehensive set of ready-to-use widgets that cover the majority of terminal
UI patterns. Every widget is composable, styleable, and designed to work naturally with Ratatui's
layout and rendering pipeline. Whether you need a simple bordered container, an interactive
scrollable list, or a full cartesian chart, there is a built-in widget for the job.

All widgets are re-exported from `ratatui::widgets`, so a single import covers everything:

```rust
use ratatui::widgets::{Block, Paragraph, List, Table, Chart, /* … */};
```

## Stateful vs. Stateless Widgets

Most widgets are **stateless** — you construct them fresh each frame with the data you want to
display and call `frame.render_widget(widget, area)`.

A handful of widgets are **stateful**: they track scroll position, selection index, or other
interactive state that must live outside the render function. These implement `StatefulWidget` and
are rendered with `frame.render_stateful_widget(widget, area, &mut state)`.

```rust
// Stateless — constructed and rendered each frame
frame.render_widget(Paragraph::new("Hello!"), area);

// Stateful — state lives in your App struct
frame.render_stateful_widget(list, area, &mut self.list_state);
```

<Tip>
  Store stateful widget state (e.g. `ListState`, `TableState`, `ScrollbarState`) in your
  application struct, not inside the render function. Constructing a fresh state every frame
  discards the scroll position and selection.
</Tip>

## Feature Flags

The `calendar::Monthly` widget is behind the **`widget-calendar`** feature flag. It is not
included in the default feature set because it pulls in the [`time`](https://crates.io/crates/time)
crate as a dependency.

Enable it in `Cargo.toml`:

```toml
[dependencies]
ratatui = { version = "*", features = ["widget-calendar"] }
```

All other widgets described in this section are available without any additional feature flags.

## Using `ratatui-widgets` Directly

Most applications depend on the top-level `ratatui` crate, which re-exports everything. If you are
building a widget library or want finer-grained dependencies, you can depend on the
`ratatui-widgets` sub-crate directly:

```toml
[dependencies]
ratatui-widgets = "*"
```

<Note>
  The crate published as `ratatui-widgets` on crates.io is the official sub-crate extracted from
  the Ratatui workspace in v0.30.0. An older, unrelated crate previously used that name and has
  since moved to `tui-framework-experiment`.
</Note>
